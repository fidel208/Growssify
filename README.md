# Growssify
Growssify is a clean, intuitive, full-stack financial dashboard application engineered to help both onboarding newbies and experienced business experts monitor their operational cash flow seamlessly. 

By bridging real-time data inputs with automated metrics tracking, the application eliminates complex bookkeeping, letting business owners focus on scaling their operations.

## ✨ Key Features

* **Real-Time Cash Flow Tracking:** Instantly log single-source business operations under distinct `Revenue` and `Expense` ledger headers.
* **Dynamic Interactive KPI Cards:** View localized snapshot data metric components showing **Today's Sales** and **Monthly Balance Turnover**.
* **Visual Revenue Breakdown:** Automatically calculates and displays the ratio between Monthly Profits and Expenses using a responsive custom CSS conic-gradient pie chart.
* **Fiscal Performance Tracking Matrix:** Dynamic vertical bar graph scaling that visualizes your **12-Month Yearly Net Income ($Revenue - Expense$)** performance rules on the fly.
* **On-Demand Statement Exports:** One-click data aggregation that compiles your entire historical transaction archive into a downloadable standard `.csv` spreadsheet.
* **Secured Data Pipeline:** Complete authorization shielding powered by JWT (JSON Web Tokens) and safe password processing architectures connecting to a relational backend layout.


## Tech Stack Architecture

### Frontend (Client Interface)
* **Structure & Styling:** Semantic HTML5, CSS3 Custom Properties (Variables), and CSS Media Queries for fluid, screen-pinned responsive layouts.
* **Behavior Engine:** Vanilla JavaScript (ES6+) utilizing decoupled asynchronous Fetch API modules, complete state synchronization patterns, and unified single-page application (SPA) routing blocks.
* **Third-Party Engines:** FontAwesome Vector Typography Icons, Google Material Symbols Layout Libraries, and EmailJS integrated support pathways.

### Backend (Server Infrastructure)
* **Runtime Environment:** Node.js
* **Web Framework:** Express.js (Model-View-Controller request matching pattern)
* **Database Engine:** PostgreSQL (Relational schema architectures)
* **Security Protocol:** Object-oriented JSON Web Tokens (`jsonwebtoken`) & state cache verification middleware routers.S
